# Campaign workspace

Stage 7 uses Streamlit native widgets, a light white working surface, pale slate
sidebar, dark navy text and a deep teal primary action (#086F67). Native sans
labels and tabular numerals keep uploaded records legible. No imagery, hero
metrics, decorative cards, gradients or entry animation.

Navigation separates Campaign preparation from Historical evaluation. The
primary view presents source selection, preview, compact campaign controls,
then a ranked result table. A compact labeled summary carries model estimates,
not oversized KPI tiles. Dataset and parameter changes invalidate results
immediately; downloading always exports the exact API response last displayed.

Native keyboard focus, labeled controls, visible loading, actionable errors,
empty guidance and table horizontal scrolling are retained. A narrow viewport
stacks native columns and collapses the sidebar. This is a reversible local
implementation under the user's standing autonomy directive; no new standing
visual preference was requested or recorded.
