# Campaign workspace

Mode: Operate. Primary action: produce a capacity-limited campaign CSV through
the existing API. Surface contract: sample or bounded CSV → validated preview →
capacity/cost/value/mode → API result → download. Historical report navigation
is independent of API availability and input scenario settings.

Implementation chooses native Streamlit composition under the explicit staged
brief and user's autonomous-execution instruction. Visual exploration is
bounded to this functional surface; no image comps, decorative assets or
standing workflow preference are needed for the task.

Candidate material considered: bank statement, analyst workbook, queue console,
research appendix, call sheet, planning worksheet, and audit ledger. The seeded
sixth direction, planning worksheet, fits the preparation workflow. Native
controls and generous action targets from consumer surfaces improve clarity;
no alternate identity is adopted. First viewport explains the decision and
exposes source and assumptions. Results must never outlive their exact inputs.
