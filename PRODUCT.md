# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The agreed Stage 7 plan uses Streamlit, with the existing local FastAPI service
performing scoring and campaign selection. Python 3.12; PyCharm workflow.

## Users

The project author learns and demonstrates an end-to-end bank campaign decision
engine as a GitHub portfolio project. The Turkish conversation establishes the
working language. A campaign planner audience is an implementation assumption.

## Purpose

Load label-free candidate features, specify call capacity and cost/value
assumptions, inspect a ranked list, and export the API's selection unchanged.

## Constraints

The existing nine-feature contract and frozen model remain unchanged. No new
holdout evaluation, model fitting, claimed causal effects or achieved profit.
Historical evaluation and unlabeled candidate scenarios must be separate.
CSV upload must have explicit size/row limits and readable errors.
Local operation and PyCharm run instructions are required. No public deployment
or account access is part of Stage 7.

## Voice

Turkish task labels and errors; official category strings retain source spelling.
Model/assumption estimates must be clearly labeled.

## Open decisions

No brand assets or visual identity were supplied. This stage uses Streamlit's
native controls and a restrained light working surface as a reversible local
implementation choice under the user's instruction to proceed autonomously.
